# 橫波與駐波機設計器（v1.0.0）

扭擺式（Shive 型）橫波與駐波機的參數化 3D 列印設計器：兩條平行 2 mm 圓鬆緊繩當扭轉軸，竹籤橫桿垂直穿過中心夾塊，兩端套列印配重；底座分段列印、鳩尾榫拼接。

- 網頁：靜態網站放在 `docs/`（esbuild＋Three.js＋Manifold-3D；3D 預覽與下載的 STL 用同一份網格）。
- 從頭自行建模；扭擺式波動機概念參考 J. N. Shive 的波動機與 HeiLaut「Wave Machine」（CC BY-SA）的教學構想，未使用其模型檔。

## 功能
- 參數表單：振子數、間距、端距、軸心高、竹籤直徑與長度、配重尺寸、夾塊尺寸、雙繩間距、繩徑、繩座夾緊量、PLA 公差、竹籤孔公差、底座每段最大長度、M3 螺絲孔開關、刻度線、每條繩拉力（只用於估算）。
- 3D 預覽整機（右端可切換固定端板／自由端板），以及扭轉波示意動畫（脈衝、前 3 個駐波；依估算波速，未實測）。
- 估算面板：轉動慣量、扭轉常數、波速、脈衝跑完全程時間、兩端固定與右端自由的前 3 個駐波頻率、列印件數量與重量（估算、未實測）。
- 自動檢查：每件都在 25×25 cm 平台內（每邊留 5 mm）、夾塊與配重最薄壁、最大擺幅不碰桌面或底座、相鄰配重間隙、配重與端板距離。
- 下載 STL（已是列印擺放、免支撐）：中心夾塊、配重、底座各段（第 1 段與最後一段含立柱）、固定端板、自由端板、羊角栓、試印小件組（夾塊＋配重＋鳩尾接縫短段）；組裝說明與零件清單 TXT；一鍵 ZIP。

## 預設參數（執行長核准的規格）
雙平行繩（間距 12 mm）、2 mm 圓鬆緊繩、一條繩繞回＋列印羊角栓、右端可換固定端／自由端板、配重盲孔套竹籤端點膠、軸心高 110 mm、間距 25 mm、30 個振子、竹籤 Ø3.0×250 mm、底座鳩尾榫可加 M3 螺絲。

## 開發
```
npm install
npm test            # 網格封閉、免支撐、平台內、射線實測尺寸、零件配合、物理估算
npm run build:pages # 輸出 docs/
```
